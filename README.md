## 📖 About

ASTRA is a long-term personal AI assistant project that I'm building from scratch to learn software engineering, Python, automation, and artificial intelligence.

The goal is to create an assistant that can:

- 💻 Control my Windows PC
- 📱 Integrate with Android
- 🧠 Remember conversations and preferences
- 🎤 Understand voice commands
- ⚡ Automate everyday tasks
- 🤖 Use AI to understand natural language

This project is being developed version by version, with each release adding new capabilities.

---

## ✨ Current Features (v0.5)

- Interactive command-line interface
- Display system information
- CPU usage monitoring
- RAM usage monitoring
- Current time display
- Command help menu
- Open Windows applications
- JSON-based application configuration
- Modular project architecture
- Git version control

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Akash-061/ASTRA.git
```

Go into the project:

```bash
cd ASTRA
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it:

### Windows PowerShell

```powershell
.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run ASTRA:

```bash
python -m app.main
```
